Permanently blocked — self-protection & evasion

Hardcoded on every gateway and cannot be relaxed from the dashboard:

  • Self-protection: /usr/local/bin/eshu-*, /etc/eshu-*, /var/run/eshu.*, eshu.db*
  • Evasion: $(which …), `which …`

The command-safety patterns (rm -rf, mkfs, dd, firewall flush, power) now live in the Blocklist below and can be relaxed — use “Core defaults” to restore them.

Web Fetch Allowlist

Per-agent allowlist for web_fetch_url. Everything not listed is blocked; an empty allowlist denies every fetch. Domains only — no wildcards, paths, ports, userinfo, or IP literals. Saving an enabled policy also grants web_fetch_url to this agent.

This is separate from the SSH command policy above; Save Policy applies immediately to MCP, not to gateway policy sync.
