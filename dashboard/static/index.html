Override Mode

Remove Gateway

This will permanently remove gateway control

The uninstall script will run on the remote host to remove all Eshu components. This action cannot be undone.

Uninstall remotely

Runs Eshu's uninstaller on the host and deregisters it. Requires the gateway to be online with its poller running.

Force remove from dashboard

Deletes only the dashboard record — for decommissioned or never-completed hosts.

A still-running gateway will re-register on its next poll (~30s), so force-removing an operational gateway may not be permanent.
